# Constitution

## North Star
100k급 도시에서 도시 생성–교통–접근성–도시발전을 설명 가능하게 결합한 시뮬레이터를 만든다.

## Non-negotiables
- S2 before S1
- external-data learning 금지
- baseline fallback 필수
- immutable WorldState
- explicit units
- multirate scheduler
- cache invalidation rules
- deterministic replay

## Deferred
- lane-level microscopic default
- RL/LLM-first
- ECS/plugin-first
- distributed multi-GPU

## Merge bar
- spec/task linkage
- tests pass
- benchmark not regressed
- docs updated if contract changed
