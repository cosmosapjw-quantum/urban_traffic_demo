# Glossary

- WorldState: 시뮬레이터 전체 상태 트리
- S2: WorldState contract + multirate scheduler
- S1: mesoscopic hybrid core
- generalized cost: 경로/링크 선택에 쓰는 시간 단위 비용
- accessibility: zone/household/job 관점 도달 가능성 지표
- lagged feedback: 같은 tick에서 닫히지 않는 느린 피드백
- candidate path set: OD별로 유지하는 K개 경로 후보
- path-size logit: 경로 겹침 보정이 들어간 선택 법칙
- active trip pool: 현재 이동 중인 trip/agent 집합
- lane grammar: 차로 블록/오프셋/인터페이스/노드 규칙을 가진 도로 문법
- interface synthesis: base/shift/transition/ramp 연결부의 on-demand 생성
- replay: 동일 seed + journal로 다시 실행하는 절차
