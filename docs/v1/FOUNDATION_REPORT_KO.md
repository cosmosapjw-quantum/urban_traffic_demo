## 1. 원래 프로젝트와 완성 범위의 연결

원 PRD의 목표는 약 10만 주민의 도시 생성, 집계 교통, 일반화 비용 경로선택, 접근성, 느린 개발 피드백이었다. 원 `001`은 계약·불변 상태·다중 시간척도·평일/주말 수요·집계 수송을 최소 범위로 두고 UI와 개별 시민 생애 모형을 제외했다. 이번 계획은 그 규모를 유지하되, fingerprint만 기록하는 재현성과 대리 성능점수를 실제 상태 복원과 실제 24시간 계측으로 강화한다.

V1은 **렌더링 없는 연구 시뮬레이터**다. 기본 8×8km와 10만 주민, 승용차·정해진 노선의 버스·화물, AM/PM·귀가·서비스·배송, 지형과 교량·램프, 지연 정보와 합법 경로선택, 느린 개발 갱신이 하나의 실행 경로에 연결되어야 한다. 지속하는 단위는 주민 개인의 매초 위치가 아니라 활동 상태를 가진 집단이다.

3D 게임, 완전한 대중교통 배정과 환승 최적화, 주차 미시동역학, 외부 데이터 학습, JAX/GPU 및 Rust 중심 재작성, 실도시 보정, Cities: Skylines 대비 우월성은 이 릴리스 범위 밖이다. 이를 후속 노드로 몰래 추가하지 않는다. 학술적으로 완전한 모든 차량 상관의 폐쇄 정리를 얻어야만 공학적 V1을 끝낼 수 있다고 정의하지도 않는다. 대신 선택한 폐쇄식의 가정과 검증 범위를 명시한다.

선택한 수송 계보는 PacketNetwork다. 기존 Model/PackedModel/ordered_network는 역사적 대조와 반례로, 연속속도·차간거리·주기 ring 모듈은 국소 이론 검산으로 유지한다. 새 주제마다 별도 도시 solver를 추가하는 방식은 중단한다.

## 2. 지도 M01: 면적측도를 수송 입력으로 바꾸기

기존 AreaAccess는 블록 내부의 균일 평면 활동 prior에서 실제 경계 출입구까지의 내부 최단시간을 계산했다. 이번에는 그 quadrature를 출입구별 지연법칙으로 컴파일했다. 새 공공도로를 건설하거나 모든 블록의 인구분포를 실측으로 재추정한 것은 아니다.

입력은 확률가중치와 시간, 출입구를 갖는 표본 `(w_i,t_i,g_i)`다. 출입구와 시간 bin별로

\[
W_b=\sum_{i\in b}w_i,\qquad
\mu_b=\frac{\sum_{i\in b}w_it_i}{W_b}
\]

를 계산하고, bin을 `W_b δ(t-μ_b)`로 표현한다. 임의의 bin 중심이 아니라 조건부 평균을 사용하므로 총확률과 출입구별 확률, 전체 시간 1차 모멘트가 보존된다. 분산은

\[
\operatorname{Var}_{\rm original}(T)
=\operatorname{Var}_{\rm compressed}(T)
+\sum_b\sum_{i\in b}w_i(t_i-\mu_b)^2
\]

로 분해한다. 마지막 항을 버렸다는 사실을 숨기지 않고 출력한다. 각 원래 표본을 같은 bin 평균으로 옮기는 명시적 결합은

\[
W_1(\mu,\widehat\mu)\le\sum_iw_i|t_i-\mu_{b(i)}|
\]

라는 1차 Wasserstein 거리의 상한을 준다. 이전 공간 quadrature의 평균 오차 상한은 별도로 보존한다. 이 두 오차는 실제 활동분포 prior의 오차나 p95의 오차를 인증하지 않는다.

같은 확률측도의 입력 순서·조각 수 변경은 표현 중복이다. 서로 다른 시간을 같은 평균으로 치환하는 것은 수치 근사이며 게이지가 아니다. 출입구별 조건부 법칙을 요청하면 원래의 출입구 확률도 반환한다. 각 출입구에 전체 인구를 다시 복제하는 실수를 막기 위한 계약이다. 일반화된 외부 비용은 물리적 접근시간으로 사용할 수 없다. 상위 profile에는 이 구별의 완전한 메타데이터가 없으므로 생산자가 `external_costs`를 정확히 선언해야 한다는 제한을 남겼다.

실제 하천도시 block109의 384개 표본은 28개 atom, 목적지 block59의 384개 표본은 30개 atom으로 줄었다. bin 폭은 2초다. 평균 접근시간은 각각 28.531182795초와 31.188841783초로 유지됐다. 평균 절대 압축 이동은 각각 0.464342685초와 0.491940790초다. 이것은 접근법칙의 압축 결과이지 전체 시뮬레이터 메모리의 같은 비율 감소를 뜻하지 않는다.

## 3. 교통 T01: 도로 진입이 여정의 출생을 지우지 않도록

기존 PacketNetwork의 `.step`은 현재 도로 입력시각을 여정 출생시각으로 사용했다. 이미 10초 동안 접근한 질량을 도로에 넣으면 앞선 시간이 사라지는 반례가 있었다. 실제 부모 동작을 통해 두 실패 시험을 기록하고, 원래 출생시각의 질량가중 1차 모멘트를 받는 `.step_measures`를 추가했다.

질량 `m [veh]`, 원래 출생 모멘트 `B [veh·s]`, 도로 경계에 도달한 시각 `s [s]`에 대해 이미 발생한 체류량은

\[
I_{\rm inherited}=ms-B.
\]

이를 `pre_entry_seconds`로 보존한다. 현재까지의 도로 시스템 체류량에는 포함하지만, 도로 내부·도로 입구 대기·도로 간 이관 체류와는 분리한다. 예전 `.step(tag,mass)` API는 `B=m*s`를 사용해 이전 물리 동작을 유지한다. 상태 의미가 확장됐으므로 identity 버전을 올렸고, 예전 fingerprint가 무조건 같아야 한다고 요구하지 않았다. 미래 출생시각이나 음의 모멘트는 입력 오류로 거절한다.

새 JourneyModel은 선택한 PacketNetwork 앞뒤에 출입구 조건부 접근·이탈 법칙을 붙인다. 내부 이동시간은 정적인 지연분포다. 접근이 끝난 시각이 도로 solver의 격자 사이에 있으면 다음 경계까지 기다리며, 그 수치적 대기를 물리적 접근과 따로 기록한다.

공공도로에서 유출한 질량을 곧바로 완료 처리하지 않는다. 실제 도로 유출 서비스 구간 `[a,b]`에 목적지 지연 `d`를 더한 `[a+d,b+d]`에서만 전체 여정을 완료한다. 부분적으로 완료된 구간의 질량과 시각 모멘트도 분할한다. 상태는 불변이며 예산 초과 시 원래의 whole-journey checkpoint를 반환한다.

매 단계 다음 두 장부를 검사한다.

\[
N_{\rm released}=N_{\rm completed}+N_{\rm origin}+N_{\rm public}+N_{\rm egress},
\]

\[
I_{\rm total}=I_{\rm origin}+I_{\rm entry\ grid}+I_{\rm public}+I_{\rm egress}.
\]

이 구조는 같은 이동을 중복 계산해서는 안 된다. 이번 실제 도시 시험에서는 원래의 `private:109:out`, `private:59:in`을 제거하고 분포적 접근·이탈로 **교체**했다. 그것들을 그대로 남긴 채 접근시간만 추가하지 않았다.

현재 origin과 destination은 경로 및 출입구에 조건화된 독립 주변분포다. 상관이 있는 여정은 joint law가 필요하다. 또한 새 지연법칙은 혼잡과 차간거리 안전을 해상하는 사설 도로가 아니다. 원래 사설 연결의 capacity를 없앤 뒤 전혀 다른 비교를 같은 도시 성능 향상으로 말하지 않는다. 공공도로의 스칼라 활동도와 시간경계 혼합은 그대로이고, 연속속도 pair 모형은 이번에 도시 수송에 통합하지 않았다.

## 4. 실제 연결 시험

부모 하천도시의 실제 경로 `0:3:109>59`에서 두 사설 연결을 제거하고 7개 공공도로를 재사용했다. 동일한 신호 계획과 고정 경로에 2대 상당량을 출발시켰다. 배경 10만 주민의 교통은 넣지 않았다. 대조는 같은 공공도로에서 접근·이탈만 0으로 둔 경우다.

| 항목 | 접근 0 대조 | 면적 접근·이탈 |
|---|---:|---:|
| 여정 완료량 | 2 veh | 2 veh |
| 전량 완료 관측시각 | 305 s | 364 s |
| 전체 평균 여정시간 | 302.222222 s | 333.411064 s |
| 최대 저장 record | 7 | 290 |
| 도로 수송 방식 | 동일 PacketNetwork | 동일 PacketNetwork |

분포적 접근 사례의 체류량은 다음과 같다.

| 성분 | veh·s |
|---|---:|
| 출발 블록의 물리적 접근 | 57.062365590 |
| 도로 진입 격자 대기 | 0.920269148 |
| 공공도로·그 입구 대기·이관 | 546.461809707 |
| 목적지 블록 이탈 | 62.377683566 |
| 전체 | 666.822128010 |

최대 분해 잔차는 `1.1368683772161603e-13 veh·s`다. 새 모형에서 도로를 모두 빠져나갔어도 목적지 지연이 남으면 미완료로 유지하는 별도 시험을 통과했다. zero-access는 부모 도로 시계와 같은 관측을 주었다.

접근 평균과 이탈 평균의 합은 약59.72초인데 전체 평균의 증가는 약31.19초다. 접근으로 도로 도착시각과 신호 위상이 달라져 공공도로 체류도 달라졌기 때문이다. 따라서 원래 통행시간에 평균 접근시간을 단순히 사후 가산하는 것과 동적으로 연결하는 것은 다르다. 이 한 사례를 실제 도시 효율 향상으로 해석하지 않는다.

2대 상당량을 표현하면서 최대290개 기록이 필요했다. 개별 차량 객체를 만들지 않았지만, 이것만으로 경량성이 충분하다고 볼 수 없다. 계획의 P01은 실제 프로파일에 근거해 이 분포·arrival fragmentation을 처리하며, 서로 다른 물리나 시간을 정확한 표현 중복이라고 오인해 지우지 않도록 한다.

## 5. 검증과 실패 기록

최종 고유 시험은 부모234 + access6 + birth2 + journey7 + plan7 = **256개**다. 156개·79개·21개의 서로 겹치지 않는 묶음이 각각 종료코드0으로 통과했다. 마지막 계획 정규화 뒤 V1와 packet 관련33개를 다시 실행해 통과했다. 부모 참조시험12개가 포함된 복원 작업공간의 결과이며 전체 원격 저장소 CI가 아니다.

기존 birth-reset과 미래 출생모멘트에 대한2개는 실제 행동 RED/GREEN이다. 새 지도 코드가 없을 때의 최초 import 실패는 행동 RED가 아니며, 이를 성공적인 TDD라고 기록하지 않는다. 다른 새 검사는 구현 후 회귀가 포함된다. Wolfram 명시적 평가에서 평균보존·분산분해·전체 체류의 경계 상쇄·출생모멘트·출구시각 이동의 잔차5개가0이었다. 자연어 Context의 관련 없는 자동 결과는 검산 근거에서 제외했다.

CPython3.13.5에서 실행했다. Python3.12, 전체 repository의 conftest·패키징·CI, 별도 독립 subagent 심사, 실측 보정, 전일10만 주민 실행은 NOT_RUN이다. 이 차이를 바로 해결할 다음 작업은 I01이다.

## 6. 전체 계획과 다음 실행

PLAN.json은21개 노드다. 현재 P00/M01/T01은 VERIFIED_SCOPED, 나머지18개는 PLANNED다. 이 비율은 제품 완성도가 아니다. bootstrap PR에서 I01을 수행한 뒤 네 노드의 증거를 확인해 통합한다. 선행 수용 없이 별도의 새 연구 브랜치를 계속 늘리지 않는다.

각 노드는 입력·산출물·파일·모형 가정·계약·불변량·관측·시험·완료조건·실패분류·예산·롤백·PR을 갖는다. 공통 증거·PR 검토 항목은 같은 JSON의 node_defaults에 있고 생성 문서에는 노드마다 펼쳐진다. PLAN.json의 상태만 ACCEPTED로 바꿔도 release 검사는 통과하지 않는다. 모든 G-* gate의 실제 영수증 경로와 SHA256을 확인한다. 이 검사는 파일 바인딩과 구조를 확인하며 과학적 진실을 자동으로 입증하지 않는다.

공학적 목표는 로컬의 3개 10만 주민 시나리오를 각각24시간, 각3회 실행하고 case당 wall time7200초 이내·peak RSS8GiB 이하를 계측하는 것이다. 이는 목표 수용문턱이지 현재 성능 결과나 약속이 아니다. 문턱 미달을 통과시키려고 목표를 조용히 낮추지 않으며, 변경이 필요하면 계획 PR과 사용자 승인을 요구한다.

이 작업에서 main은 변경하지 않았다. 실제 PR 번호와 마지막 게시 SHA는 PUBLICATION.json을 확인한다. 앞으로의 문서와 실행은 새 기준 계획의 다음 노드만 따른다.

`validate --release`는 현재 의도적으로 종료코드2와 BLOCKED를 반환한다. 원격에는 규범 JSON과 생성기, DAG 원문, 간결한 개요와 실행 보고서를 게시한다. 전체 생성 Markdown·PR 표·DAG PNG/SVG는 납품에 포함되며, fresh checkout에서도 render로 재생성한다. 이 번들은 단독 과학 검증용 소스·부모 입력을 포함하지만 전체 저장소를 대체하지 않는다.

## 원문헌 대조의 범위

Stępniak & Jacobs-Crisioni(2017), DOI10.1016/j.jtrangeo.2017.04.001의 publisher 원문에서 공간 집계와 통행시간 가중·접근성의 관계를 확인했다. 그 논문의 특정 가중식이나 데이터 적합을 이 구현에 전용하지 않았다. Manout et al.(2021), DOI10.1007/s11067-020-09505-6는 SciSpace/Exa 후보 및 공개 초록으로 확인했으며 direct publisher 조회는 timeout이었다. centroid connector의 위치·정의와 구역 내 이동의 생략을 구분해야 한다는 동기로만 사용했다. 새 압축·체류 식과 수치는 직접 유도와 코드 실행의 결과다.
