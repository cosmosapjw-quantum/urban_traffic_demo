## R3/C3 · finite-horizon stochastic order with censoring, source representation invariants

**Model.** Let mass labels z∈(0,M] be in the immutable order of physical FIFO entry. For j=1,2 let cumulative actual service S_j(t) be right-continuous nondecreasing with no premature service (T_j(z)≥b(z) for p_r(z)>0), and define right-continuous hitting time T_j(z)=inf{t:S_j(t)≥z}, with inf∅=∞. The same source history, fixed input and route assignments must be used for both clocks; no rerouting or density-induced endogenous source change is covered. For any finite observation horizon H, define the censored residence W_{j,H}(z)=T_j(z)−b(z) if T_j(z)≤H, otherwise +∞ (including permanently unserved labels). It lives in extended nonnegative seconds [0,∞]. Route probability law is P_{r,j,H}(B)=M_r^{-1}∫p_r(z)1_{W_{j,H}(z)∈B}dz, with event time endpoints and atoms handled by the fixed source ordering. The route completion fraction C_{r,2}(H)=P(W_{2,H}<∞) ≥ C_{r,1}(H). Any nondecreasing finite measurable cost φ of the censored extended delay is therefore no worse whenever its integral is defined. This is an explicit distributional upgrade over the previous mean/squared-moment theorems, and allows constructing route-specific threshold and median reliability tests in a nonstationary mixed-route setting.
