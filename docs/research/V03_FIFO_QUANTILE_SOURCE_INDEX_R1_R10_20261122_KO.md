## R3/C3 · finite-horizon stochastic order with censoring, source representation invariants

**Model.** Let mass labels z∈(0,M] be in the immutable order of physical FIFO entry. Each z has a fixed physical birth time b(z), route intensity p_r(z)≥0 with Σ_r p_r(z)=1 and finite route input mass M_r=∫p_r(z)dz>0. For j=1,2 let cumulative actual service S_j(t) be right-continuous nondecreasing with no premature service (T_j(z)≥b(z) for p_r(z)>0), and define right-continuous hitting time T_j(z)=inf{t:S_j(t)≥z}, with inf∅=∞. The same source history, fixed input and route assignments must be used for both clocks; no rerouting or density-induced endogenous source change is covered. For any finite observation horizon H, define the censored residence W_{j,H}(z)=T_j(z)−b(z) if T_j(z)≤H, otherwise +∞ (including permanently unserved labels). It lives in extended nonnegative seconds [0,∞]. Route probability law is P_{r,j,H}(B)=M_r^{-1}∫p_r(z)1_{W_{j,H}(z)∈B}dz, with event time endpoints and atoms handled by the fixed source ordering. This normalization uses ALL original route source mass, not just completed mass, thereby preventing survival-selection bias.

**Derived constructive theorem:** If S_2(t)≥S_1(t) pointwise for every physical clock, then T_2(z)≤T_1(z) for every source mass label z (monotonicity of generalized inverses, including plateaus) and W_{2,H}(z)≤W_{1,H}(z) pointwise in extended time. Consequently F_{r,2,H}(u)=P(W_{2,H}≤u) ≥ F_{r,1,H}(u) for every finite reliability threshold u, and generalized route quantiles Q_{r,2,H}(q)=inf{u:F_{r,2,H}(u)≥q} ≤ Q_{r,1,H}(q) for q∈(0,1), with inf∅=∞. The route completion fraction C_{r,2}(H)=P(W_{2,H}<∞) ≥ C_{r,1}(H). Any nondecreasing finite measurable cost φ of the censored extended delay is therefore no worse whenever its integral is defined. This is an explicit distributional upgrade over the previous mean/squared-moment theorems, and allows constructing route-specific threshold and median reliability tests in a nonstationary mixed-route setting.

**Important boundary:** The completed-only conditional delay distribution P(W∈B | T≤H) need NOT preserve dominance: an accelerated service may newly complete a later high-age cohort, raising its completed-only mean or median while all source-matched individual delays shrink. The physically correct comparison is the censored *fixed-source denominator* measure, not completed-only selection. Also, the microscopic distribution P cannot be reconstructed from only aggregate first/second birth moments (N,H,J); the original 100k native historical route checkpoint has no per-label b(z) distribution. A separate source-tagged observer would be necessary before claiming real city quantiles. Historical physical source moment/packet identity remains untouched.

**Exact constructed example:** four interval-cohort blocks z∈[0,2] route A born0, z∈[2,3] route B born1, z∈[3,5] route A born1, z∈[5,6] route B born2, each unit Lebesgue mass per coordinate. Slow S_1(t)=t/2 and fast S_2(t)=t for t≥0 give T_1=2z, T_2=z, valid T≥b. H=7, u=3: F_A,slow(3)=3/8 and F_A,fast(3)=3/4; F_B,slow(3)=0 and F_B,fast(3)=1/2. Completion fractions A: 5/8→1, B: 1/2→1. A route 50% quantile slow=4s, fast=2s. B 75% quantile slow=∞, fast=7/2s. Exact Wolfram piecewise integrals independently returned {3/8,3/4,0,1/2,5/8,1,1/2,1,True}, all rational.

**Computational source form:** Use Fraction for cohort masses, endpoints, birth clocks and piecewise-linear cumulative service, with deterministic generalized inverse and route-wise pushforward CDF/quantile. No Python float rounding. The test oracle must differentiate H censoring from a threshold condition on delay and reject nonphysical T<b, negative speed and source route weights.

## R4/C4 · constructive alternatives and test-first RED evidence

**Physics selection:** Candidate A is the fixed-source censored FIFO full-route delay distribution with route-wise stochastic dominance, conditional on pointwise cumulative service order. Candidate B is delay first/second moments alone, which do not identify quantiles or all reliability thresholds. Candidate C is per-vehicle Monte Carlo resampling with different route choice, which invalidates a fixed-source monotonic comparison. Candidate D is completed-only conditional travel-time quantiles; newly completed slower cohorts can make those appear WORSE with faster service, so they are not valid targets for an unconditional improvement theorem. Candidate A is selected, with a conservative route mass at +∞ for unfinished cohorts and exact Fraction oracle for an original labelled source.

**Numerical construction:** Source is a list of contiguous ordered mass intervals [z0,z1] with route mark and constant original birth clock b, service is a continuous nondecreasing exact piecewise affine S(t), and observation horizon H. This permits exact O(number of source blocks) threshold CDF:
F_{r,H}(u) = M_r^{-1} Σ_{k:route r} max(0,min(z1_k,S(min(H,b_k+u)))-z0_k).
In physical words, a vehicle contributes to F only if it exited by H AND its actual age at exit was ≤u; because the service cumulative curve is nondecreasing, these two conditions are captured by the earlier deadline min(H,b+u). For each source interval the delay w(z)=T(z)-b is piecewise affine wherever S has nonzero slope. A finite sorted list of source-interval endpoints and service-curve mass knots produces exact rational delay breakpoints, enabling exact quantile inversion, with quantile +∞ when q exceeds the completed route mass fraction. This is a constructive finite-horizon algorithm not requiring hypothetical infinite service.
