## S06: bounded ready-stock coalescence theorem
In current finite-response code a packet with target D has readiness passage(max(D-x,0)), and distance increment min(dx,max(D-x,0)). For every already-ready packet D<=x, both are zero (readiness time zero, distance zero); for equal future target both quantities coincide. Thus collapsing a contiguous group of already-ready packets to last target or a group of identical future targets preserves these two kinematic quantities in the current frozen state, including common per-cell class mass and latent closure in real arithmetic. Does not preserve ordered FIFO composition of a merged group.
