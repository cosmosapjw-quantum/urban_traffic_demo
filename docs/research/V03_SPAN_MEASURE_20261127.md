## S02: exact block rank representation
Read prior trace: 67,269,906 physical road rows, 1,187,008 packets; 18,666,739 incoming refs at rejection. The existing 12B tuple is (event index, path offset, control index). Event backing owns tag/mass/birth; no need to duplicate f64. For block B=128, let integer column base a=min and width w=ceil(log2(max-min+1)), including w=0 for constant columns. Row rank i decodes a+bits(i*w,w); no change of order or floating arithmetic. Three independently packed columns, two 64bit header words, exactly 16+16*(w_event+w_offset+w_control) bytes/full block; raw 1536B fallback when not smaller. O(1) rank access, fixed 128-ref reusable tail; allocate once per full block (not per event). For any block, byte count <=1536, no compression assumption needed for correctness. A conservative preflight must charge new raw block and its independent staging tail plus both descriptor allocations; credit only sealed packed blocks, never prospective compression. Prior partial row traces (6,427,966 same-rate contiguous rows) motivate block locality but do not prove the achievable ratio. Sources: Lemire/Boytsov, DOI 10.1002/spe.2203 (binary packing), public https://github.com/lemire/FrameOfReference and https://github.com/fast-pack/simdcomp (README retrieved; no code copied, no license compatibility or measured performance transfer asserted). Original implementation in Rust. Exact rank access tested across widths 0..32, signed-domain irrelevant for integer indexes, constant and wide fallback, multiple block growths. This is lossless transient representation, not a new physical approximation.

## S05: conservative time-bin measure projection (new physical closure)
Literature motivation: Camilli, De Maio, Tosin, Transport of measures on networks, NHM 12(2), 2017, DOI 10.3934/nhm.2017008; interval transport plus junction distribution. Nonlocal measure transport existence/continuous dependence literature (SciSpace abstract search) motivates measure-valued representation, but does not establish stability of MetroFlow nonlinear FIFO/rate decisions. Do not invoke its theorem without matching conditions.
At each destination and immutable (tag,offset) define nonnegative measures mu=sum_i m_i U_[a_i,b_i], nu=sum_i bmoment_i U_[a_i,b_i], U uniform probability or point mass if a_i=b_i. Original continuous row assumes uniform within interval; do not confuse birth moment with entry clock. For fixed disjoint bins I_k=[l_k,r_k], compute m_k=sum_i m_i*|I_k intersect [a_i,b_i]|/(b_i-a_i), B_k analogously, and replace each interval restriction by uniform measure with these masses on I_k. Points kept at their original clock (prototype only accepts points at upper boundary with identical bits, otherwise exact fallback). No dropping positive mass, no merging distinct tag/offset, no cross-epoch mixing. Wolfram integral sanity check True/True/True for uniform bin mass and centroid. Direct proof: each interval's overlaps partition its support, hence sum_k m_k=sum_i m_i and sum_k B_k=sum_i B_i in real arithmetic. For finite binary64 implementation require per-cell mass/birth residual within explicit original-scale tolerances; do not claim bitwise equivalence.
For each bin and mark, couple original restricted measure to its uniform replacement within same I_k, with transport distance <=h=max bin width. Thus W1(mu,Pi_h mu)<=h*mu(total) (unnormalized, veh*s), W1(nu,Pi_h nu)<=h*nu(total) (veh*s^2). For any L-Lipschitz phi, integral error <=L*h*mass. In particular entry first-moment error <=h*M. For any observation clock in one bin the per-tag cumulative discrepancy is <=that bin's mass; at all bin boundaries the cumulative counts agree. If a fixed characteristic speed is bounded by v_max, corresponding distance error is <=v_max*h per coupled rank; a frozen finite-response latent law dp/dt=lambda(p_eq-p), p,p_eq in [0,1], yields local latent-moment error <=lambda*h*M. These are conditional local bounds, not a global bound under nonlinear node allocation, readiness threshold or changing routes. Test coupled traffic observables rather than assume contractivity. 
Cardinality theorem: per receiving cell per tick, if K distinct (tag,offset), B bins, and endpoint points only, no more than (B+1)*K output rows and B+1 packets, regardless of distinct nonpoint edges or interval overlap count. Compare original worst-case O(K*#edges), actual interval sweep may be lower. A finite day still has multiple entry epochs retained and input row work; no unconditional O(1) full-engine bound.
