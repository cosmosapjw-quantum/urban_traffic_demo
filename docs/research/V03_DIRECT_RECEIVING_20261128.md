## S02. Interval transport as a marked measure; constructive representation theorem
A receiving stream of marks k=(route,offset) has positive measures dM_k and dB_k on admission clock x (mass veh, birth first moment veh*s). Each positive interval [u,v] carries constant densities m/(v-u), B/(v-u); point arrivals stay Dirac atoms and retain endpoint bits. On the common refinement of all endpoints E, define M_{kj}=sum_i m_i*(b_j-a_j)/(v_i-u_i) and analogously B, only for i whose support contains the open cell (a_j,b_j). At any endpoint e in E, the cumulative marked inflow F_k(e) equals the sum of refined-cell masses before e plus the explicitly ordered atoms through e. This follows by finite additivity of lengths on each source interval. For any contiguous window with endpoints in E, the cumulative difference gives its exact marked mass and birth moment. Consequently the residence-age functional t*M-B is also preserved. This is a real-arithmetic conservation statement, not an assertion that merging different FIFO heads, or replacing original rounded multiplication/division with a single fraction, is bit-exact. For positive nonempty head, a common fractional service restriction acts on all its marks, so a representation that decodes every ordered (tag,offset,m,B,a,b) identically preserves all original per-row numerical operators; induction over event sequence preserves the physical trajectory under identical accepted inputs, provided resource admissions succeed. 
For each interval reduce source ordinals with the same original f64 operations. Pass 1 discovers exact key support and whether the bounded stack bit-pair dictionary is profitable; pass 2 emits codes and new keys directly, never constructs dense moment Vec on accepted dictionary path. With N>=32 and d<=256, choose dictionary only if N+16d+128<16N+96 and existing plan's stronger N+16d+128<16N. Reused key Arc contributes zero new payload. Otherwise preserve original dense path. Need preflight expansion scratch before planning, use exact capacity checks, retain final newly allocated bytes only. Original compact checkpoint wire still expands kind2/3. Dictionary lookup equality is on both u64 bit patterns. All intermediate sums preserve their original reduction order, and the clip variant keeps its original formula.
The stronger long-term alternative is cumulative marked rank curves with interval evaluation, but actual node consumption/finite response and rounded operations remain constraints. No general compression guarantee for high-entropy marks, no claim of bounded logical row count or physical full-day equivalence.
