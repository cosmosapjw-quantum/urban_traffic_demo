**Scope of independent physical theorem:** For ordered priority entry times `tau_i` (a true FIFO order, e.g. cell entry or explicit node crossing order), the *serve-quota response of the priority-coordinate first moment* can reconstruct the priority histogram. Original `Part.birth` is not necessarily this `tau_i`: for paths with different upstream delay, origin birth order and current cell-entry order may diverge. Therefore a theorem about convexity of cumulative ORIGIN birth moment without additional monotonicity is false. The route-resolved count-quota curve `F_j(q)` must be added to reconstruct each route destination, and a global route count with no priority coordinate is insufficient. This strengthens R1's finite global-moment impossibility by characterizing a continuous family of sufficient physical observables and a stability estimate.
