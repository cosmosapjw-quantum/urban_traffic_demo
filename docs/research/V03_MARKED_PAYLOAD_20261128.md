## S02 — marked rank transport and exact factorization (derived)
A uniform interval packet has immutable ordered route-offset keys K=(k_i), mass m_i and birth first moment B_i, common target and interval [a,b]. Interpret in real arithmetic as positive measure dmu_k=m_i dq on normalized internal FIFO rank q in [0,1], and dnu_k=B_i dq. Restriction to rank [u,v] gives (v-u)(m_i,B_i), preserves order and route keys. For disjoint adjacent rank slices, moment additivity follows by integrating constant densities; concatenating the slices reconstructs the original measure. A node with a common head-service fraction f, determined from weighted mass and footprint/successor totals, consumes the prefix and leaves the suffix. Induction over original event sequence yields identical node/road evolution if all key, interval and **ordered** per-row numerical operators agree; this is not a license to average different heads or change finite-response/receiving conditions. Binary64 exact restriction must evaluate each original multiplication in order (not collapse factors or replace sum of rounded products by f times a sum). Reuse immutable key Arc for a remainder if every scaled mass stays positive, and allocate only its new moments. Filtered-underflow fallback uses old representation. This is a constructive exact data factorization; full persistent rank view is further work.
General bit dictionary: if ordered moment pairs x_i=(bits(m_i),bits(B_i)) take d distinct values, encode index map i->c_i and exact dictionary; decode x_i=D[c_i] with identical order and bits. No rounding or physical quotient. Storage 16d+wN+metadata vs16N (w=1/2/4 bytes). Necessary strict savings after metadata, not universal. For physically homogeneous proportional segments, a factorized real-arithmetic density gives a constructive route to further model reduction, but bit-identical multiplication chains cannot generally collapse. Read-only wire census tests whether bit dictionary is worthwhile before engineering it.
Exact preflight lifetime: the max-cell raw combine workspace belongs to receiver phase. In timed event-index incoming + lifetime path, source offer group/sort/packing is bounded by explicit offer reserve (4 Part+Offer per original offer; all group rows <= offers), plus final packed allocation guarded. Motion and source transfer do not materialize the max-cell combine arrays. Receiver after dropping source workspaces already performs measured local allocation checks. Admit source-only initial guard and offer packing without obsolete future combine workspace, retain all other owner/events/observation charges and later local checks. Legacy arms keep old checks. This is an explicit phase specialization, not budget relaxation or proof of full-day memory bound.
