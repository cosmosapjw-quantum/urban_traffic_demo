## S02 — marked source-clock quotient (derived)
For each private road journey leg l (fixed source cell, route tag, class and route offset 0), represent access rows by a finite positive measure nu_l(db,dr)=sum m_i delta_(b_i,r_i), where b is intent birth time, r=b+delay is readiness, both seconds, m is vehicles. The prepare observer at aligned grid t_k=t0+k dt consumes rows r<=t_k+eps (eps=1e-10s), once, in original ordinal. Define absolute first-consumption tick k(r) including overdue rows at current tick. The physical coupling converts every such row to (tag,m,m*b,None,None). In v1_road.rs::step_state, offers first create one source packet per start cell and combine by (tag,offset,a,b interval endpoints); here offsets are 0 and both intervals None. The road sees canonical per-tag M_l(k)=sum m_i and B_l(k)=sum m_i*b_i after combine. Before this combine, born, birth1, inherited and class admitted sums are linear in real arithmetic. Thus replacing any fixed (l,k) group by one positive row with mass M, birth B/M and ready centroid R/M (R=sum m_i*r_i) preserves all road source packet fields, all source scalar increments and every due mass. Birth <= ready and readiness cell inequalities are convex, so d=R/M-B/M>=0. Induction on coupled deterministic real-arithmetic tick maps with fixed declarations shows equality of future road/ledger evolution, including FIFO and downstream supply because the *same canonical boundary packet* enters that operator. This does not assert a general FIFO quotient for interior packets; different tags, physical interval marks, bus/freight or changed route/schedule observers are not mixed. No assumption of homogeneous traffic composition at a receiving node is made.
For a creation tick g, r<=t_g+D for finite max access delay D (parent hold=t_g-b cancels birth; independent source b<=t_g). In a committed state at T, all rows not retired before T must have r>previous grid deadline. Thus a persistent (leg,absolute consumption tick) representation needs at most ceil(D/dt)+2 live cells per active leg, independent of number of raw law products and creation ticks. This is an actual finite-memory bound for the restricted boundary model; periodic projection is a step toward that ring, not a claim the current full engine obeys the bound. One local proposal with common birth can be projected before raw row allocation; old pending backlog can be coarsened across generations at a fixed clock. In binary64 check original rounded readiness predicates, positive mass, representative birth <= current clock, nonnegative delay, reconstructed r cell, and mass/birth/ready moment tolerances; fallback if not valid. Road scalar accumulation and reassociation can differ in low bits, so new identity and matched control are necessary. B has units vehicle*s, B/M seconds. Exact source-preserving optimizations (no-due queue fast path, ordered expansion) keep original identity.
