Let fixed legal candidate paths have positive path sizes PS_i, costs C_i in seconds, temperature Theta>0 seconds and dimensionless beta. P_i proportional PS_i^beta exp(-C_i/Theta). With fixed choice set and path sizes, perturb C_i by delta_i with |delta_i|<=epsilon, interpolate linearly. dP_i/ds=-(P_i/Theta)(delta_i-E_P delta). The total variation derivative is bounded by epsilon/(2Theta), since E|delta-E delta| <= sqrt(Var(delta)) <= epsilon. Thus TV(P,P')<=min(1,epsilon/(2Theta)). This is a local fixed-registry bound, not valid across availability/candidate changes. If every suffix cost error <=epsilon, choosing an alternative with estimated gain >2epsilon guarantees strictly positive actual gain, because true gain >= estimated gain-2epsilon. No measured epsilon in this lab; threshold is behavior, not guaranteed true benefit.

For two symmetric routes, differential estimated cost kappa x, x=p-1/2, logistic derivative -1/(4Theta), relaxation lambda in (0,1]. Linearization with one medium-step delayed share gives x_(n+1)=(1-lambda)x_n-lambda*g*x_(n-1), g=kappa/(4Theta)>=0. Polynomial z²-(1-lambda)z+lambda*g. Schur conditions: lambda(1+g)>0, 2-lambda+lambda*g>0 and 1-lambda*g>0. For this domain stability iff lambda*g<1. At equality complex unit roots (except degenerate boundaries); no-delay stable iff lambda(1+g)<2. Not a nonlinear or network stability theorem; actual lab uses discrete choices, completed-link observations, lagged delivery rather than this mean relaxation. Wolfram checked three polynomial expressions and logistic derivative, with symbol warning; independent arithmetic/root check below is load-bearing. Expired or not yet delivered reports revert to declared priors; this is a distinct observation mechanism, not infinite age extrapolation.

## Scope of graph and physical transaction

Installed graph is a versioned subset of a fixed authored physical registry. Adding a previously uninstalled link creates a new Routing graph and state; all existing commitments keep exact prefix, destination and owner and rebind identity only if still legal. Removing a link is rejected while any live committed path uses it (conservative, including traversed prefix). Empty physical stock alone is insufficient; after drain actual removal is permitted. Reported temporary closure is a no-new-entry constraint; existing occupants can leave. Topology publication is an explicit exogenous control event (known when installed); cost observation is delayed. Reroute only at ready boundary, with zero already-crossed fraction; retain current link and prefix, physical mass/birth and owner, no rewriting of scheduled service commitments. Candidate path costs use actual completed link passage times at completed boundary and observed no-entry status, with priors for missing/expired reports. Declared availability-conditioned cost is not a route-total travel-time observation or a calibrated prediction.
