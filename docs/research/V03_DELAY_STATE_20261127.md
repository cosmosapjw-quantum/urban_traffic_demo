## S02. Finite-memory delay calendar and protected observer quotient (derived)
Use positive marked measures on each leg l, with birth b and ready r in seconds, mass m in carrier units. The entry observable at aligned clock t_k reads the sum of mass and birth moment at the first due tick. Pending egress after the preceding retirement has completion stamp r (since r>t_previous+eps); its next retirement cell is the first t_k with r<=t_k+eps. For all private child observers with fixed profile start s_c and dwell d_c, define H_l=min_c(s_c-d_c), or +infinity when no child exists; a service child or unobserved profile semantics sets H_l=-1. Only pending egress atoms with r<=H_l and not crossing the rounded retirement predicate can share a bucket. The current-ready/clamp region is not merged. The original service legs are protected. For a positive cell, M=sum m_i, B=sum m_i*b_i, R=sum m_i*r_i, with representative (M,B/M,R/M-B/M). Convexity preserves b<=r and the retirement cell; within hidden horizon, every future nonzero child query includes the entire cell. At each discrete tick, injection adds sufficient statistics, retirement emits the bucket and clears it. Induction gives real-arithmetic boundary mass, birth and completion moments, eligibility/release and hence coupled road boundary observables, assuming fixed declarations and the prior source canonicalization. General non-hidden cuts must remain separate; this is not a claim of full FIFO interior or dynamic route equivalence. The clamp max(t,r) must precede aggregation for overdue rows; we retain these raw.
If D_l bounds delays from generation to retirement and all future observables distinguish C_l mark cells, each active leg has at most (ceil(D_l/dt)+2)*C_l live sufficient states, after draining inherited backlog, for a fully supported quotient. Absolute tick tags, not modulo residues alone, prevent alias across revolutions. The state update is a positive discrete transport in residual-delay coordinate j: X_{l,j}^{k+1}=X_{l,j+1}^k+A_{l,j}^{k+1}, boundary outflow X_{l,0}^k; the three components of X have units mass, mass*s, mass*s. This is a finite-dimensional Markov realization of the discrete observer, not a finite-dimensional realization of arbitrary continuous delay kernels. If observers change or raw fallbacks persist, the bound applies only to projected support.
Implementation choice: sparse ordered clock partitions of immutable StageQueue blocks, rather than dense ring indexed by all possible legs/ticks. Sort only newly appended tail on canonical in-memory path; merge per-leg within each touched clock partition, share untouched Arc blocks, rebuild once if a decoded wire lacks partition boundaries. On insufficient scratch or unsupported grid keep original queue. Still materializes representative Access rows each touched partition, not persistent full expansion statistics. Binary64 representatives recheck birth/ready and exact due predicates; reassociation distinct identity. This is a surgical change of representation, not road physics.
Exact validation counting partition: count rows per leg, prefix sum, stable scatter masses in original traversal order, then original Sum per leg. Same ordered add sequence as sorting (leg,ordinal), O(N+L) work and 8N+8L (two u32 arrays) scratch versus 16N sorted scratch; only use if within previous envelope. No assumption on expansion width.
