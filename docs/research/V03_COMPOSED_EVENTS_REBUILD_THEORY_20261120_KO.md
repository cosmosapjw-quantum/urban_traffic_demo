## R2. Four serious reconstruction routes

A. Exact paired incoming/Mark storage. Every accepted transferred Part in the original native step has one Mark=(class,mass,speed,latent). Original incoming Part already owns tag and exact mass, and class=routes[tag].class. Keeping only MarkCompact=(speed,latent) with source-order one-to-one zip yields a mathematically lossless Mark decoder with 16B instead of 32B per mark. Replace the old existing 2×(48+32)=160B per incoming-row structural allowance with same multiplier 2×(48+16)=128B after proving exact one-to-one storage, without changing any numeric cap. This route is the minimal native production experiment, while event Vec and packet genealogy remain unchanged.

B. Full immutable marked-cohort DAG and event/incoming streaming. Retain original source Part bitwise transformation order and use shared fragments and structured event consumers. Requires new checkpoint-version contract and exact queue/node/eager oracle; flat legacy serialized output has Ω(number of independent output rows) work. This is the stronger exact long-term route, not proven feasible from clone-sharing alone.

C. First-order multi-commodity cumulative link transmission and geometric partial FIFO. Route-integrated counts and link travel delay replace timestamp packet histories; a physically defined lane/turn-pocket constraint can release an unblocked direction independently. Memory is bounded by chosen links, routes and delay history, not by individual packet splits. Exact original strict FIFO/vehicle birth history is lost without a mapping theorem; new model rather than V03 equal-output refactor. See Wright et al. 2017 DOI 10.1016/j.trb.2017.09.001 and Jin 2015 DOI 10.1016/j.trb.2014.12.006.

D. Micro-to-macro kinetic/conservative six-moment state. Already implemented independent KCMB code evolves binary self-driven control sigma, continuous v/U conditional moment fields with local transition and conservative finite-volume Godunov flux, including finite storage and network node. O(6×classes×cells) for fixed network/mode counts, but finite moments cannot reconstruct arbitrary exact route order or each individual birth-time. Modified BGK traffic theory supports conditional stop-go waves (Herty et al. 2020 DOI 10.3934/krm.2020010). This is a radical opt-in comparator only; no arbitrary fitted coefficients.

## R3. Exact paired Mark theorem and IEEE order obligation

For each successful native road-step transfer to a receiving cell j, the original code emits a Part p and a Mark m=(k,M,u,q) into incoming[j] and marks[j], in the same append order. Here k=class(p)=routes[p.tag].1, M=p.mass, u=speed, q=latent; Part offset increment and interval time rewrite do not alter tag or mass. In the source pending-offer route, the same one-for-one append also holds. Define projection pi(m)=(u,q) and decoder D(p,(u,q))=(class(p),p.mass,u,q). For every corresponding pair, D(p,pi(m))=m bitwise: an identity under original per-row assignments, not a statistical approximation. Induction over the accepted append stream proves alignment of the two per-cell arrays in every successful physical return; source verification and independent tests must check both append paths.

Speed calculation must use the same ordered terms p.mass*u that original sum(mass*speed) consumed. Per-class latent sums must retain the old sequence: first survivor terms, then received marks in arrival order. Therefore the two sums and BTreeMap class grouping may be computed by iterating zip(incoming,compact_mark) BEFORE combine(incoming) destroys raw packet ordering. All individual f64 multiplication order stays exactly the same; mutation/exception allocation order may differ, which is separate from successful-output bit equality. An invariant check requires raw Part/compact-Mark lengths to match. Validation must compare actual native complete checkpoint SHA at 25600 and 25650 to the prior source-bound opt-in result.

## R5. Scientific falsifiers and stop conditions

A successful source step MUST have one compact Mark per incoming Part, retain Part ordering, exact per-class mass and birth, and the original total velocity/latent fsum binary64 sequence; a mismatched length must fail rather than silently truncate zip. Merging Part keys before extracting class/mass destroys the pairing and must not occur. A red signal in shared strict FIFO can block route B behind arbitrarily small route A, so route-aggregated KCMB/partial-FIFO cannot match all source outputs even when its class mass/velocity moments match. No future statistical method can reconstruct an arbitrary ordered route sequence from finite generic moments alone. State this negative theorem and present an opt-in finite conservation/shock comparator alongside source-preserving Mark reduction.

## R6. Exact active-source-index bitset refactoring (derived, not a new traffic model)

The original interval splitter iterates selected active source indices in ascending order using BTreeSet<usize>, and for each endpoint interval [a,b] applies the original individual f64 operations m=fl(fl(p.mass*(b-a))/(pb-pa)), birth=fl(fl(p.birth*(b-a))/(pb-pa)), then original source-index tie order before combine. The selected index set is sparse and varies by endpoint. Replace the tree with a two-level fixed bitmap: low bits words[index/64], summary bits summary[word/64] flagging nonempty low words. Both data levels are arrays of u64, with ceil(n/64)+ceil(n/4096) words for n total immutable source Part rows.

**Lemma B1 (exact ordered output).** Insertion and deletion maintain (i) low bit membership iff source index is currently active, (ii) summary bit membership iff its 64-source-index word is nonempty. Induction over each endpoint's start/end event sequence proves equivalence with the old BTreeSet membership; lexicographic iteration over increasing summary word bits, increasing low word bits produces strictly increasing original source indices, so the per-row f64 evaluation and the exact ordered sum/combine group sequences are identical. The old point-index special cases, inclusive/exclusive endpoint semantics, signed ±0 equality and prefix/suffix route tags are unchanged. Duplicate insert/remove idempotence is tested at sizes across 64/4096 boundaries. This is a property of selected index order and unchanged per-Part operations, NOT a proof about an arbitrary new traffic model.

**Complexity and resource contraction.** Active membership toggles take O(1) deterministic bit operations versus BTreeSet O(log n); iteration is O(number of active source indices + ceil(n/4096)) instead of tree walk O(active). Fixed active-set bit backing is O(n/8) bytes, compared with the previous conservative structural budget charge 96n bytes for possible BTreeSet nodes. The existing three sorted endpoint/index arrays of 16n bytes and point-index workspace of 8n bytes remain; the former event_index_bytes term charged n(3×16+8+96)=152n bytes. The new source charges n(3×16+8) + 8ceil(n/64)+8ceil(n/4096)+256, covering concrete fixed active and summary bit buffers, fixed-capacity point workspace and extra fixed metadata. Edge endpoint arrays and per-interval split/combine workspace remain separately charged as before. These are **algorithmic structural budget** changes following an actual changed data structure, not an increase to the fixed native cap or subtraction of an unproven Arc alias. RSS/time is unmeasured until real source-bound runs. Physical model, Mark projection, source, clocks, transport/FIFO rates remain frozen.

**Qualification:** Iterator scanning over the summary bitmap introduces a per-edge O(ceil(n/4096)) overhead; a pathological configuration with few active indices but many edges could run slower than BTreeSet. The code is a scoped candidate: source-locked actual 25650/25700 physical replay must test bytes and run time, not rely on asymptotic notation.

## R8. Exact FIFO non-identifiability from finite order-invariant moment state

**Proposition (derived, constructive).** Let S carry route-resolved six local Markov speed/control moments per link, but not the order of the distinct route components within the head of a shared physical lane. Let F(S,signal) be a deterministic turn-flow prediction depending only on these instantaneous moments, the same link geometry, and the same red/green signal. There exists no such F that equals strict head-of-line FIFO exit for every physically admissible ordered incoming state.

Proof: choose two permitted states AB and BA, each with one unit of route-A and one unit of route-B mass, identical conditional speed and self-propulsion control values. Their six per-route moments, pending/released/completed aggregates, link occupancy, geometry and model ID are identical, while their ordered lane head strings are A→B and B→A. Block the A outlet red, permit the B outlet green. In AB, A at the head prevents any B transfer, hence Q_B(AB)=0. In BA, the B head can traverse at finite positive capacity; with the documented unchanged unit-model fixture, a checked one-step transfer is Q_B(BA)=0.05 veh. Were Q_B=F(S,signal), equality of S and signal would imply Q_B(AB)=Q_B(BA), contradiction. Both Python and Rust implementations using an explicit FIFO shadow produced the same witness and exact class ledgers.

This is not a theorem against resolving *spatial longitudinal position*, a kinetic distribution with enough route-order state, or a finite-state rule for a bounded restricted catalog of orderings. It is specifically a no-go for reconstructing **strict universal route FIFO from instantaneous order-invariant finite moments alone**. Consequently the KCMB moment-only branch is a new physical closure, not a hidden same-checkpoint refactor of the legacy packet engine. Traffic where true separate turn lanes exist can physically depart from a shared FIFO head model, and this change must be justified by actual geometry.

## R9. Finite-state synthetic-day execution and numerical claim limits

For a fixed directed link network of L links and K route/class species, the current KCMB corridor/network representation stores six conditional speed/control moments per (link,route) and three cumulative boundary ledger scalars per route, hence **6LK+3K scalar values**, apart from fixed geometric/routing parameters and per-step bounded scratch. Under frozen per-class local generator, finite-rate positive transition, admissible CFL, finite receiving metres and conserving node allocation, the modeled mass identities are explicit; no per-vehicle ordered birth/entry interval rows are introduced. This bounded-size statement depends on the *fixed network K and L*, not on exact original per-vehicle FIFO or universal city-level realism.

The source-grounded C10 experiment ran two **synthetic** 86,400s networks with dt=0.5s, 172,800 steps each and unchanged fixture rates and constant 0.02 veh per route per step. Model A: three links, one shared approach lane, 42 scalars, 613-byte checkpoint. Model B: physically widened separate 30m turn pockets, five links, 66 scalars, 802-byte checkpoint. Both completed a full model day on Rust KCMB backend, checkpoint exact round-trip, fixed scalar count, and periodic independent conservation/space checks. Source-run examples: A elapsed about 14.8s, B about 20.6s (one run, no statistical performance advantage claimed); max reported single-step ledger residuals about 4.94e-9 and 4.34e-9 veh, and 174 independent periodic checks per case.

The output sizes and wall times are finite observations of two tiny networks. They provide **zero evidence** that a 100,000-resident River/Coastal/Valley model, with observed OD/source demand or identical V03 microphysical model, can be represented in 42–66 scalars. In particular, the geometry differs between the cases and their throughput comparison is not a same-geometry controlled causal experiment. The numeric checks do not by themselves establish observational fidelity, a general PDE entropy condition or perfect FIFO.
