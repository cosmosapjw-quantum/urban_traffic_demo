## R3/C3 · Formal physical upgrade and exact-arithmetic contract
For ordered physical packet cohorts (k=1,...,K), each packet contains nonnegative class/route masses `m[k,r]` and stored birth-time first moments `B[k,r]` (units mass×seconds), with positive head mass `M[k]=sum_r m[k,r]`. Let `s` be an admitted FIFO service volume, `0<=s<=sum_k M[k]`. If `s` stops in packet `h`, define its fraction `alpha=(s-sum_{k<h} M[k])/M[h]`, applying that *same* alpha to every route and birth-moment component in the head. The class cumulative functions are `N_r(s)=sum_{k<h}m[k,r]+alpha*m[h,r]`, `H_r(s)=sum_{k<h}B[k,r]+alpha*B[h,r]`.
**New theorem target (physical, not performance):** each FIFO head has slopes `dN_r/ds=m[h,r]/M[h]`, `dH_r/ds=B[h,r]/M[h]`; `sum_r N_r(s)=s`, first-moment conservation; two adjacent packets can be coarsened with **all prefix class mass + first moments invariant** if and only if both vectors of per-total-mass slopes agree. Necessity rules out merging distinct cohort age profiles despite identical total age/mass. Coupling prior weighted node rates `q_i` to `s_i=q_i Δt` gives explicit route/age downstream observables; additional dynamic head changes need recomputation, not extrapolation.
Scope: exact rational/arithmetic physical sector with proportional within-packet split, route-indexed moments, FIFO source order. Observability equivalence is *weaker* than binary IEEE and checkpoint byte equality; source is NEVER auto-coalesced on this theorem alone.
**C3 implementation interface:** new research-only `metroflow.v1.fifo_cohort_moments` immutable `CohortPacket`, `CohortPart`, `fifo_prefix_moments` specifies the exact physics oracle. Deliberate `NotImplementedError` remains until focused source-independent RED test, so it is *not* a completed simulation feature.

## R5/C5 · Constructive physical FIFO cohort-moment theorem (proof) + exact Rust phase solution
**Theorem FPM (Finite FIFO Prefix Moments, constructive):** Let an ordered FIFO cell have K finite packets with route-indexed source masses `m[k,r]>=0`, first birth-time moments `B[k,r] in R`, and `M[k]=sum_r m[k,r]>0`. For admissible served mass `s in [0,M_total]`, take the first packet index h such that `s<=sum_{k<=h}M[k]`; define `alpha=(s-sum_{k<h}M[k])/M[h]`, with boundary convention s=0 meaning no packet served. Define cumulative route serveds `N_r(s)=sum_{k<h}m[k,r]+alpha*m[h,r]` and moments `H_r(s)=sum_{k<h}B[k,r]+alpha*B[h,r]`. Then:
1. **Existence, uniqueness, positivity, conservation:** proportional partial packet service is the unique FIFO prefix mass allocation with a common cut fraction inside the head. `0<=N_r(s)<=sum_k m[k,r]`, `sum_r N_r(s)=s`; the sum of output birth moments equals exactly the sum of served component moments, not a heuristic mean-age update.
2. **Regularity and transport coupling:** Within any open packet interval `s in (sum_{k<h}M[k],sum_{k<=h}M[k])`, derivatives are `dN_r/ds=m[h,r]/M[h]`, `dH_r/ds=B[h,r]/M[h]`. `N_r` is nondecreasing, 1-Lipschitz: `0<=N_r(s2)-N_r(s1)<=s2-s1` (because route fraction belongs to [0,1]). If `|B[k,r]|<=T*m[k,r]`, then `|H_r(s2)-H_r(s1)|<=T*(s2-s1)`. Coupling to a frozen-head WPF node service allocation q_i with `s_i(t)=integral_0^t q_i(u)du` yields route flux `dN_{ir}/dt=(m[head_i,r]/M[head_i])*q_i(t)`, and birth-moment flux analogously, for almost every time before head changes. Thus both physical observables can be preserved at each downstream node without inventing a route-agnostic mean cohort age. Finite head changes yield piecewise measurable flux, not a global smoothness theorem.
3. **Exact constructive coarsening certificate (if and only if):** Two adjacent packet cohorts A and B can be replaced by a single packet of total mass `M=M_A+M_B` and route components `(m_A+m_B,B_A+B_B)`, while preserving **N_r(s),H_r(s) for *every* intermediate FIFO service cut** iff `m[A,r]/M_A=m[B,r]/M_B` and `B[A,r]/M_A=B[B,r]/M_B` for every route r. Proof: On the first open service interval the original slope vector is `(m_A/M_A,B_A/M_A)`; on the second it is `(m_B/M_B,B_B/M_B)`. A single merged packet has constant slope `((m_A+m_B)/M,(B_A+B_B)/M)`. Equality of all cumulative functions implies their derivatives coincide on both nonempty intervals, proving necessity. Conversely the common slopes integrate to the same piecewise-linear continuous function from s=0, proving sufficiency. This is a positive, sufficient **physical** compression/closure criterion for first-moment-observed FIFO networks. It does **not** authorize merging distinct source packet order, changing IEEE summation or immutable binary checkpoint: `SCIENTIFIC_EQUIVALENCE` of route/birth prefix observables is weaker than `BYTE_IDENTITY` required by current V03.
**Concrete physical counterexample:** m_A=(3,1), B_A=(6,5), m_B=(6,2), B_B=(12,10); A and B have equal normalized route/birth slopes and can be merged observationally without losing route/age flux at any service cut (not just the endpoint). Change B_B,route2 from 10 to 16: masses and final route totals still match, but birth flux at a service cut s=2 differs from the naive merged age representation. This shows why route-specific birth moments are a *real physical* closure constraint, not mere memory bookkeeping.
