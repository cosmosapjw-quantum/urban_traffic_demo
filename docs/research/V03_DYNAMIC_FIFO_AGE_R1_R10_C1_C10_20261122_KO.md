## R5/C5 · constructive dynamic FIFO travel-time theorem and native source repair (verified scoped)

**Theorem TDA (route-resolved transport delay and capacity dominance, derived):** Fix an ordered non-overtaking FIFO source with total cumulative mass M>0 and finite route index set R. Its label z∈[0,M] has nonnegative route fractions p_r(z) with sum_r p_r(z)=1 and fixed route-specific birth-time first-moment densities b_r(z) (units seconds per unit total mass); the previous fixed packet model provides p_r=m_kr/M_k and b_r=B_kr/M_k on each packet label interval. For a feasible nondecreasing continuous cumulative service s_j(t), eventually s_j(t)≥M, define the generalized inverse service time T_j(z)=inf{t:s_j(t)≥z}, finite almost everywhere. Physical total *actual sojourn time* of route r is
`D_{jr}=integral_0^M [T_j(z)*p_r(z)-b_r(z)] dz` (mass×seconds).
The physical route outflux `dN_r/dt=p_r(s_j(t))*s'_j(t)` almost everywhere; `sum_r dN_r/dt=s'_j(t)`, so route-level mass is conserved. If scenario 2 dominates scenario 1 by `s_2(t)>=s_1(t)` at all times while keeping exactly the same original queued source stream and birth moments, then `T_2(z)<=T_1(z)` for every admissible label z where both inverses are finite. Therefore
`D_{1r}-D_{2r}=integral_0^M p_r(z)[T_1(z)-T_2(z)]dz>=0`
for EVERY route r. Equality characterizes zero route mass on labels where service clocks differ. This is constructive, route-resolved and independent of a numerical memory optimization. It makes an intervention prediction under fixed source composition, without the stronger chronological-birth assumption needed for monotone age of a *partially served* cohort.
**Proof:** For any z, s_2(t)>=s_1(t) means the threshold-crossing set {t:s_1(t)>=z} is contained in {t:s_2(t)>=z}, so their infima obey T_2<=T_1. For a non-overtaking queue, the same label z crosses each scenario's output at its inverse T_j(z); conservation along a route yields the infinitesimal output mass p_r(z)dz, and the conditional birth-time contribution is b_r(z)dz. Subtract route delay integrals and use p_r(z)>=0. On each constant-rate segment, T(z)=t0+(z-s0)/q, so exact rational closed forms follow from the two endpoint squares; no source reorder or probabilistic assumption. Time-dependent q may come from the original node sending/receiving WPF each event interval, but global service dominance is an explicit condition, NOT asserted for all coupled networks.
**Exact illustration (units mass,seconds):** two source packet route components `((m,B)_1,(m,B)_2)=[((2,0),(1,1)),((1,2),(1,3))]`. Fixed source birth times are all <= t=10. At physical demand service rate 1, T_1(z)=10+z; doubling available service rate to 2, T_2(z)=10+z/2 for 0<=z<=5.
