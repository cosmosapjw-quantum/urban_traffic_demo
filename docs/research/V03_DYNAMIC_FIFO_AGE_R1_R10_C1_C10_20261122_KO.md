## R3/C3: dynamical constitutive statement and candidate source admission contract
Let one fixed chronological FIFO source have ordered cohorts k with route components (m_kr,B_kr), M_k=sum_r m_kr>0, and conditional mean birth clock tau_kr=B_kr/m_kr where m_kr>0. Define cumulative departure mass s(t) (a nondecreasing absolutely continuous function satisfying 0<=s<=M_total) from the original supply/demand constrained node q(t)=s'(t)>=0. Let N_r(s),H_r(s) be the original exact cohort prefix integrals. **Derived dynamic observables:** the total age carried by the actually departed route r at physical clock t is A_r(t)=t*N_r(s(t))-H_r(s(t)); instantaneous output composition dN_r/dt=q(t)*m_{h,r}/M_h and age-bearing flux dH_r/dt=q(t)*B_{h,r}/M_h within a fixed head h. If N_r>0, mean output age a_r(t)=t-H_r/N_r is sensitive to actual *service* rather than a single mixed aggregate age. These formulae extend the prior static source prefix model to a *nonstationary birth-time transport and observable closure*, not memory accounting.
