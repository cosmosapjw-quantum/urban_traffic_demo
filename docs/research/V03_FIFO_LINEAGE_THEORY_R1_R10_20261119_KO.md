## R3. 물리 상태, 유효범위, 정확성의 세 층

**Original physical Part.** Part=(tag r, path_offset k, mass m≥0 [vehicle-equiv], birth b≥0 [vehicle-equiv·s], interval endpoints pa≤pb [s]); birth is extensive first source-birth-time moment, not a normalized timestamp. Original portion operation for service fraction f∈[0,1] returns m' = fl(m·f), b' = fl(b·f), filtering m'≤0; remainder uses fl(1−f) as actually computed. Original interval_packets uses q.mass = fl(fl(m·(b−a))/(pb−pa)), likewise birth, so reassociation changes binary64. Original EventRow=(tag, source_cell, destination, mass, event_start, event_end, birth). Destination-specific geometric footprint, continuous cell speed/latent Markov state, source/road windows and junction rates remain protected separate physical variables.

**Marked finite measures.** Let Ω be the measurable mark space (route,offset,original entry interval,physical class,ready/target annotations). A batch is represented by a nonnegative finite mass measure μ on Ω and extensive birth measure β on the same mark support, with β(A)=∫_A t_birth dμ for nonnegative source birth times. The original Mixed packet can contain *different* [a,b] marks, so a normalized route-only vector is insufficient. The representations may be considered over exact real scalars for a derivation, but implementation uses IEEE binary64 and must track original arithmetical ordering.

**Link FIFO mass coordinate.** For one ordered link with total queued continuous mass M, define cumulative coordinate s∈[0,M] [vehicle-equiv] and a measurable probability kernel K_s on Ω, K_s(Ω)=1 a.e., and birth-moment density θ_s on marks. For route r set F_r(q)=∫_0^q K_s(route=r) ds [veh], H_r(q)=∫_0^q θ_s(route=r) ds [veh·s]. For a nondecreasing output cursor D(t), 0≤D(t)≤M, route output over [t1,t2] is F_r(D(t2))−F_r(D(t1)); first birth moment likewise H_r(D(t2))−H_r(D(t1)). This formalizes link-local FIFO, not the event law that determines D(t) and not arbitrary network-wide FIFO.

**Future-observation equivalence.** Let S be the full V03 state, u any admissible future control/signal/boundary schedule, O(S,u) its specified route counts, age/birth, event clocks, mass/space ledger and per-queue FIFO history. Define S~S' iff O(S,u)=O(S',u) for *every* u. An exact compression map C must satisfy C(S)=C(S')⇒S~S'. Proof: a deterministic compressed state with identical C values cannot generate different future outputs on one admissible u. The quotient S/~ is a formal minimal sufficient **set-theoretic** representation, not a computable or bounded-RAM algorithm. If original legacy checkpoint byte stream is additionally observable, its identity is a separate requirement.

**Three exactness contracts:**
- REAL-EXACT: equality of marked measure integrals and causal outputs in exact real arithmetic.
- IEEE-EXACT: identical binary64 values and signs, operation/fold and fsum order, decisions and event ordering.
- WIRE-EXACT: identical complete legacy binary checkpoint byte stream. REAL-EXACT does not imply IEEE-EXACT; IEEE matching selected observables does not imply WIRE matching; changing the checkpoint schema can be semantically sound but is not byte-identical.

**Locked source and physics assumptions:** finite input rows and finite endpoints, no NaN, nonnegative masses, no new hyperparameter/traffic fitting, no hidden alteration of time grid or route priority; no automatic equivalence of first-order LTM to original V03 finite-response dynamics. Class/latent physical evolution is not replaced by route-mass measure alone.

## R5. 구성적 정리·증명: exact measure, FIFO, memory and IEEE

Throughout L1–L10 distinguish **exact real arithmetic** (ℝ) from the actual ordered binary64 operations. Assume physically valid nonnegative vehicle-equivalent masses, a finite tag set per snapshot, admissible route/signal controls, and no silently introduced packet/timestamp smoothing.

### L1. Proportional-service vector conservation (DERIVED, exact ℝ)
Let a packet be a finite vector of row masses m=(m_j)_{j=1}^P with m_j≥0 and extensive source-birth first moments b=(b_j). For f∈[0,1], define served=(f m,f b) and remainder=((1−f)m,(1−f)b). Then their sum equals (m,b) componentwise; both mass vectors remain nonnegative; any linear per-tag extensive observable L satisfies L(served)+L(remainder)=L(original). If f>0, the normalized route composition remains unchanged: Σ_{j∈route r} f m_j / Σ_j f m_j = Σ_{j∈r}m_j/Σ_jm_j. **Proof:** distributivity f+(1−f)=1 and cancellation by f>0; same on b. □
This exactly captures the *real-valued* semantics of source portion, but a floating-point sum of separately rounded children may not equal parent bits (L6).

### L2. Marked cumulative mass-coordinate FIFO theorem (DERIVED, conditional)
Fix one link and stock M>0. Let K_s be a measurable probability measure on full marks Ω for a.e. s∈[0,M] with K_s(Ω)=1. Let Θ_s be an integrable birth-first-moment measure on Ω. For any route r, F_r(q)=∫_0^q K_s({route=r})ds and H_r(q)=∫_0^q Θ_s({route=r})ds. Assume physical service has a **nondecreasing cumulative prefix cursor** D(t) with values 0≤D≤M, and that a service subinterval (t1,t2] removes exactly the marked mass between D(t1) and D(t2). Then
  out_r(t1,t2) = F_r(D(t2))−F_r(D(t1)),
  out_birth_r(t1,t2) = H_r(D(t2))−H_r(D(t1)).
All route output masses are nonnegative; Σ_r out_r = D(t2)−D(t1) [veh]. For source positions s1≤s2, the crossing times T(s)=inf{t:D(t)≥s} satisfy T(s1)≤T(s2), hence link FIFO. **Proof:** both formulas follow by countable additivity of the marked integral over [D(t1),D(t2)]. Normalization Σ_r K_s(r)=1 yields conservation. Monotonicity gives inclusion {t:D(t)≥s2}⊆{t:D(t)≥s1}, hence the generalized-inverse order. □
**Scope:** no claim that the original V03 event allocator computes such a D(t) without amendment, or that independent links' cursors prove perfect network-wide FIFO. For Uniform packets K_s is constant across a head mass segment; for Mixed packets it must retain original time-support marks. Source point arrivals/atoms can be represented as positive mass-coordinate intervals with constant marks; input timestamp ties preserve original declared priority separately.

### L3. Exact adjacent-density coalescence criterion (DERIVED, within the marked-measure interface)
Let I1=[a,b], I2=[b,c], a<b<c, have identical physical target, ready and priority-group constraints, no distinct point mass at b, and constant per-mark mass densities ρ^1(ω), ρ^2(ω) [veh/s] and birth densities θ^1(ω),θ^2(ω) [veh·s/s]. A **single** constant-density interval [a,c] has identical mass and first-birth output on *every* subinterval J⊆[a,c] for each mark ω **iff** ρ^1=ρ^2 and θ^1=θ^2 (a.e. over marks). Proof: if both match, integrate a common density across J and use additivity. Conversely choose J in the interior of I1 and separately in I2; equality of all integrals forces the merged density to equal both old constants for each mark. Any nonzero atom at b or changed ready/target must remain separately represented because an event query can resolve it. □
Identical *total* density but unequal route vectors fails: two length-1 intervals with all route A then all route B have the same end totals as a mixed [0,2] interval with 50% A/B, yet route A output by t=1 is 1 versus 1/2. This is real-arithmetic non-equivalence, not merely float roundoff.

### L4. Conditional immutable composition-sharing complexity (DERIVED, explicitly output-sensitive)
Consider a fixed immutable P-row composition template and E partial-service operations, each producing two logical scaled views whose factor/order is stored as a constant-size node referencing a parent, with no materialization or unbounded fan-in. An eager retained-output representation may store Θ(P E) scalar rows; a persistent composition graph can hold P base entries plus at most 2E constant-size split nodes, i.e. O(P+E) stored units, while preserving the exact ℝ semantics of each view. Proof by induction on E: a split adds two nodes and never copies the already stored base array. Materializing all logical output rows still takes at least Ω(P E) operations and Ω(P E) output words if all rows must coexist. □
For general V03 merge/restrict operations, add the number J of bounded-arity expression operators/operand edges: total symbolic nodes O(P+E+J), **not** O(number of time ticks). E+J may themselves grow rapidly and an arbitrary query may traverse deeply nested expression ancestors. No unconditional RAM/time result for the V03 release follows.

### L5. Output-size lower bound for the current original event interface (DERIVED)
If a caller requires an explicit flat Vec<EventRow> of R arbitrary entries, materializing it requires Ω(R) row constructions/writes, and retaining the whole vector costs Ω(R) words. Proof: each of the R indexed output entries must be stored to provide the advertised flat vector; sublinear writes would leave some independently variable entry unspecified. Streaming may reduce **peak** resident memory but retains Ω(R) total writes/time. □
The inspected original step_state explicitly forms events, per-destination incoming Part vectors, class marks and original checkpoint Part rows. Consequently a lazy portion in isolation cannot yield end-to-end asymptotic speed/memory improvement unless the downstream event/mark consumers and potentially versioned checkpoint representation also accept compressed provenance. This lower bound applies to *explicit output representation*, not to a hypothetical oracle returning compressed symbolic views.

### L6. Binary64 nonassociativity/refactor obstruction (NUMERICALLY CHECKED finite counterexample)
Take literal binary64 x=0.1, f=0.3, g=0.7 (all strictly positive and admissible). CPython IEEE evaluation gives
  fl(fl(x f) g) = 0x1.5810624dd2f1ap−6,
  fl(x fl(f g)) = 0x1.5810624dd2f1bp−6.
They differ by one ULP. Moreover fl(fl(x f)+fl(x fl(1−f))) gives 0x1.9999999999999p−4 instead of x=0x1.999999999999ap−4. The V03 interval multiply-then-divide order has a separate witness for x=0.7, interval_width=6, parent_width=9:
  fl(fl(x·6)/9) = 0x1.ddddddddddddcp−2,
  fl(x·fl(6/9)) = 0x1.dddddddddddddp−2.
The independent finite seven-row fsum search produced a different output for Σ fl(m_i f) with math.fsum versus fl(f · math.fsum(m_i)); exact values in EXACT_THEORY_CHECKS.json. Hence collapsing a scale chain or moving coefficient multiplication outside a sum **cannot** be justified as bit-identical for arbitrary source rows. □ by explicit binary64 counterexample. A DAG that retains each primitive original f64 operation and original input/fold order can reconstruct **that fixed trace** by evaluation induction, but only if every physical branch decision is replayed on the same bits; this is a conditional sufficiency principle, not an implemented V03 correctness proof.

### L7. Route-order information lower bound (DERIVED, finite-bit tagged FIFO subclass)
Take a physically admissible strict single-lane queue of 2m identical finite-mass elements, m marked route A and m route B, with distinct ordered cumulative positions. Suppose future admissible controlled discharge reveals, one by one, the outgoing route label of all 2m elements and there is no overtaking. There are C(2m,m) different marked orders with identical total A/B mass and all common low velocity/birth moments. Every two orders yield distinct future observable route-label sequences, so by pigeonhole any **finite-bit deterministic** state sufficient for all such outputs requires at least ceil(log2 C(2m,m)) bits to distinguish them. By Stirling, log2 C(2m,m)=2m−(1/2)log2(πm)+O(1/m). □
For m=256 the exact ceil is 508 bits (verified separately). This is a **linear-in-number-of-ordered-labels** information lower bound for this admissible subclass, not a theorem of exponentially growing RAM over physical time in every traffic model, nor a universal impossibility of shared symbolic storage.

### L8. Local Markov kinetic semigroup contraction (DERIVED, frozen external fields)
On u=v/U∈[0,1], σ∈{0,1}, fixed τ>0 and nonnegative exogenous rates α(t),ν(t), define generator on smooth φ:
  L_t φ(u,σ)=(σ−u)∂_u φ/τ + λ_σ(t)[φ(u,1−σ)−φ(u,σ)],
  λ_0=α, λ_1=ν.
The deterministic flow remains in u∈[0,1] and switching rates define a positive mass-preserving Markov transition kernel P_{s,t}. Its action on finite signed measures is linear at fixed field, positive on nonnegative measures, and satisfies TV contraction:
  ||P* μ−P* η||_TV ≤ ||μ−η||_TV.
**Proof:** mass preservation/positivity follow from the stochastic transition definition and invariant speed boundaries (du/dt≥0 at 0 and ≤0 at 1). For any test |φ|≤1, |Pφ|≤1, and dual TV gives the contraction. Linearity follows by the integral definition. □
This is a kinetic/statistical-physics reason to share cohort ancestry **conditional on a fixed environment**. It does **not** imply Lipschitz stability of original V03 nonlinear density-dependent hazard/receiver switching: if rates depend on the evolving state, two different candidate measures may see different kernels.

### L9. Strict FIFO head-of-line blocking defeats a universal mass-error Lipschitz bound (DERIVED counterexample)
Consider a one-lane source at a diverge, service capacity at least 1 vehicle-equiv per test interval, route A red (zero receiving), route B green (can receive 1). State S_ε has a head A mass ε>0 followed by B mass 1; S_0 removes only ε A and leaves the same B mass. Their total-variation input mass difference is ε. Under strict head-of-line FIFO with **no bypass**, B exits 0 under S_ε but exits 1 under S_0; the B-output difference is 1, so |Δoutput_B|/||S_ε−S_0||_TV=1/ε→∞. □
Thus no state-independent finite Lipschitz constant converts arbitrary tiny leading route-mass deletion into uniformly tiny observed output errors across all signal controls. A small total-mass error tolerance by itself does not certify approximate packet coalescence. Stability can be recovered only after an independently justified restriction on the priority law, flow smoothness, gap to blocking threshold or admissible observations.

### L10. Head mixture invariance under proportional service (DERIVED, real arithmetic only)
For any packet with M=Σ_j m_j>0, route-specific desired outgoing mass N_r=Σ_{j:dest(j)=r}m_j, and footprint weighted mass W_r=Σ_{j:dest(j)=r}ℓ_j m_j, the normalized head ratios N_r/M and W_r/M are invariant under proportional scaling by f>0 because numerator and denominator both gain factor f. □
This permits a **conditional per-head cache** of route/footprint proportions while serving a head repeatedly, but service rates still respond to changing downstream supply and clock; the head ceases to be identical when route/time restriction, merge, sink, or other physical transformation occurs. In binary64, fl(f Σm_j) and Σfl(f m_j) need not agree (L6), so the cache requires an IEEE equivalence check or a different precision contract.

**Synthesis.** Exact ℝ composition-sharing and prefix-flow semantics are derivable; exact global network FIFO and IEEE old-checkpoint identity are additional obligations. Simultaneous memory+speed gain is structurally possible only if source-row duplication and explicit output materialization are both removed on the relevant path. No theorem here proves a 24-hour release fit under 8 GiB without implementing and measuring the proposed operators.
