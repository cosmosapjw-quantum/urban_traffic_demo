## S03 — measure-level theory, conservative phase decorrelation

For cohort g of mass m_g and uniform departure window [a_g,b_g], choose n_g equal-mass rank strata and q_j=(j+u_j)/n_g, 0<u_j<1. Impose u_{n-1-j}=1-u_j, with middle u=1/2 for odd n. Then q_j+q_{n-1-j}=1, so the discrete measure preserves total mass and mean departure time (a+b)/2 exactly in real arithmetic. The same rank remains paired with the return distribution; actual return still obeys arrival+dwell. Every rank lies in its own stratum; for every r in [0,1], |F_n(r)-r|<=1/n (only one partially covered stratum can contribute error). After any common deterministic access shift or positive mixture of shifts, cumulative departures/admissions obey the weighted uniform bound delta=sum_g m_g/n_g. This is a conservative deterministic bound, not a small error certificate for all network observables.

In the ideal randomized version with independent cohort phase families, each non-middle rank is uniform in its stratum. For even n the per-cohort CDF is unbiased; at a fixed t, variance of the weighted count is <=m_g^2/(4 n_g^2). For odd n the deterministic middle contributes at most m_g/(2n_g) bias. Summing independent cohort variances replaces coherent O(sum m_g/n_g) fluctuation by a root-sum-square scale. The hash implementation is deterministic and not claimed to prove statistical independence; seed comparisons measure sensitivity.

Constructive link stability proposition: for empty, unbounded, work-conserving fluid queue with constant service c>0 veh/s, cumulative exit D_A(t)=inf_{0<=s<=t}{A(s)+c(t-s)} (A(0)=0, nondecreasing, use left limits at atoms as necessary). For another arrival B with sup |A-B|<=delta, the two infima differ by <=delta, since the functions differ pointwise by <=delta. Therefore queue stocks Q=A-D satisfy sup|Q_A-Q_B|<=2delta. If a reference stock has margin K-max Q_A>2delta, the perturbed queue cannot activate storage at that link under this closure. This is a sufficient condition for a single point bottleneck with the same capacity and transport delay, not a proof for cyclic finite-storage network dynamics. It supplies a measurable route to separate grid effects from true congestion. Exact rational tests check 1..32 strata, 4 phases, stratum boundaries and 6,561 pairs of finite cumulative curves at c=3/2.

Literature context only, not a novelty claim: Nakayama et al. (2020), Quantile Estimation via a Combination of Conditional Monte Carlo and Randomized Quasi-Monte Carlo, doi:10.1109/WSC48552.2020.9384031, discusses low-discrepancy CDF estimators and randomized marginal uniformity; Boyles and Ruiz Juri (2019), Queue Spillback and Demand Uncertainty in Dynamic Network Loading, https://scispace.com/papers/queue-spillback-and-demand-uncertainty-in-dynamic-network-45ihw0hgef, motivates sensitivity to demand uncertainty; Bar-Gera and Carey (2017), doi:10.1016/j.trb.2017.02.002, highlights representation requirements for network-wide FIFO, which this link-local model does not claim.
