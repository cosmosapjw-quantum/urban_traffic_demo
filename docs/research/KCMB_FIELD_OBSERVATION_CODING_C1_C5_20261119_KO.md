# KCMB Chicago speed-only and OSM candidate adapter: coding C1–C5

2026-11-19 KST. Scope research-only. Parent source 0855fcc633a8ad7ba8b2fa065a8db13261a48178. R1–R10 theory and frozen actual official source data already pushed as 915dc8821c9dbeb3861d8fad15fa3b5e25908409. Original packet solver and 100k V03 acceptance remain unchanged.

## C1. Baseline and objective
Existing generic tools/research/kcmb_field_metrics.py requires matched observed & simulated vehicle counts and speed. Chicago Transit Tracker 4g9f-3jbs exposes CTA bus GPS-estimated segment SPEED, plus bus_count/message_count probe metadata, but no observed vehicle counts. Fabricating vehicle count or using GEH would be a scientific mismatch. The task is a new opt-in speed-only physical observation operator, offline and source-hash reproducible, with explicitly named Halsted NB segment 1221 and a source day-level holdout.

## C2. Theory-to-code mapping
The exact KCMB class equilibrium mean speed is m*=U alpha/(alpha+nu). Since U,alpha,nu,tau cannot be determined by speed mean alone, code computes ONLY scalar equilibrium-compatible calibration mean mu_cal. It does not mutate or instantiate the kinetic parameters and does not claim calibrated KCMB runtime. Individual raw city estimates in mph map to m/s using 0.44704. Official length in miles maps to metres via 1609.344. Retain calendar-date Chicago-local naive timestamps (no invented UTC). Bin is floor(local minute/10) for 07:00–09:00 and observation identity = site+direction+local date+bin. A held-out same-clock-bin comparison uses separate Mondays, 2026-04-20 and 2026-04-27. A time-of-day template is an intentionally high-dimensional diagnostic competitor, not new physical model.

## C3. Computation and numerical error
New module src/metroflow/v1/chicago_observations.py defines immutable ChicagoSegment, SpeedSample, ExcludedSpeed, ChicagoObservedSet, OsmRoadCandidate. parse_observation_days normalizes exact source rows, rejects inconsistent dates/segment/direction/geo, nonfinite numbers and duplicative clock bins, and flags -1 speed as NO_SPEED_ESTIMATE and empty bus/probe messages as NO_PROBE_SUPPORT. These flags do not produce substitute values, zero traffic counts, or dropped mass claims. evaluate_speed_only computes holdout MAE, RMSE (m/s), a sorted empirical W1 where equal sample counts, and returns flow_geh=None explicitly. One held-out day is temporally correlated and has no valid i.i.d. confidence interval.

The OSM matcher reads a bounded existing local XML fixture without network calls, selects only named Halsted highway way segments and constructs a great-circle Haversine-distance road graph. It chooses an endpoint-near connected path within 30m per endpoint and a 10% official-length tolerance; it never certifies lane count, legal one-way, actual CTA probe route or signal phase. Returned one-way/lane verification flags are False.

## C4. Resource and identity
All project mutation stays inside a new separate worktree research/kcmb-field-observation-20261119. Official raw source slices are small (12+12 records) and were frozen byte-identically in theory stage with exact SHA-256 and reproducible API query URLs at artifacts/kcmb_field_20261119/SOURCE_MANIFEST.json. The existing OSM control fixture is read-only. Module has no network client or external dependencies beyond Python stdlib. Normalize at most 5,000 rows per split; OSM bytes at most 10 MB, finite segment coords and bounded named road match; Dijkstra complexity O(V+E log V) per source candidate.

## C5. Executable behavior and red–green
The public tests tests/research/test_chicago_observations_20261119.py originally saw NotImplementedError for speed normalization, evaluation and map match; 9 related checks failed. After implementation 9 of 10 passed, while geographic matching failed. Direct independent OSM graph traversal showed a connected path; source inspection revealed the implementer had reversed candidate tuple fields (distance, node ID). Correcting tuple unpacking turned the false map-match rejection into a passing match without weakening any accepted geometry threshold.

New tests verify actual date/segment/day labels and 24 real observations, deterministic 07:00–09:00 bin indices, Chicago direction, units, calibrated speed-only baseline (calibration mean 7.972213333m/s), held-out mean 8.15848m/s, constant baseline holdout RMSE 0.5215466667m/s, MAE 0.3725333333m/s, 12-slot time-template RMSE 1.0719642621m/s, observed calibration-vs-holdout speed W1 0.33528m/s. Distinct OSM named-road candidate was recovered with start 13.04m/end 15.70m offsets and path length 836.62m versus City 836.85888m.

Invalid -1 speed (missing estimate) and probe=0 source rows are explicitly excluded with reasons. Duplicate slot, calibration/holdout date overlap, altered direction, source outside window, incorrect -2 speed, timezone-added synthetic stamp, geographically impossible OSM endpoints, missing street and incompatible official length all produce typed failures. Non-identifiability of alpha,nu,tau,U given only m* is verified by constructive families.
