## S02 — causal transport error, not uniform-density error
Let mu_k be a positive finite marked measure of admission time in seconds and mass in vehicles, including uniform densities and Dirac atoms. A bin I=(l,r] (first includes its left endpoint) maps each x to r; nu_k=(T_r)_#mu_k. T_r(x)>=x, and the bin preserves mass and birth first-moment integral independently per mark. For any s inside a bin, F_mu(s)-F_nu(s)=mu(I intersect (-infty,s]); it is nonnegative and vanishes at right boundaries. The exact local supremum over s<r is mu(I)-mu({r}), not one quarter of bin mass. In particular, moving an atom near l to r can attain the whole mass error. The previous diagnostic named generic_prefix_bound used M/4 for a right-point projection, which is not valid. The earlier 1/4 theorem for averaging a bounded continuous density on an interval remains correct and is a different operator.
On the line, for measures of equal finite mass, the nonnegative transport delay integral D=int (T_r(x)-x)dmu equals int(F_mu-F_nu) ds by Tonelli (each x contributes a rectangle from x to r). It is also the minimum cost over couplings: |y-x|>=y-x, and this coupling attains equality, hence W1=D (unnormalized veh*s). For any L-Lipschitz g, |int g dnu-int g dmu|<=L D. With a nonnegative birth-moment measure the same identity holds in veh*s^2, though this implementation constrains mass delay, not birth-density delay. Rank/order across different marks inside one bin is not retained; future FIFO network equivalence is NOT implied. Protected boundaries: receiving cell, common tick and target, route/offset and owner, class; point atoms can move only within that tick except sparse exact point mode.
Construct adaptive coarsening of a finest grid of <=16 intervals. Fine cell j has mass m_j and delay d_j=int(r_j-x)dmu. For a merged contiguous block i..j the exact causal delay is sum_{k=i}^j [d_k + m_k(r_j-r_k)]. Enforce each block D_ij <= theta*dt*sum m_k, hence total delay <=theta*dt*M. Dynamic programming over ordered boundaries, dp[j]=min_{i<j: admissible(i,j)}(1+dp[i]), obtains minimal bin count among partitions of this fixed fine grid; no assumption of monotone feasibility. Tie break by total delay then first predecessor encountered. Fine widths <=theta*dt when theta>=1/max_bins and duration<=dt, so fine solution exists in real arithmetic. In binary64 check finite accumulators and recompute achieved delay after emission; this is numerically checked with documented tolerance, not directed-rounding certificate. Sparse exact point path unchanged. Model gets separate native identity; original logical cap untouched.

## S07–S09 — from finite-delay transport to bounded resident row census

A constructive conditional long-horizon bound is available, distinct from the local projection. For a FIFO link with cumulative admitted mass A and completed mass D, assume A(t)-A(s)<=sigma+rho(t-s), a rate-latency service curve D(t)>=inf_{0<=s<=t}[A(s)+c(t-s-tau)_+], c>0, rho<=c, and no pre-initial unresolved mass (or charge it to sigma). Let H=tau+sigma/c. For s<=t, A(s)+c(t+H-s-tau)>=A(t) by the arrival bound; for s>t, A(s)>=A(t). Thus D(t+H)>=A(t), and FIFO implies every rank admitted by t has left by t+H. Units sigma veh, rho,c veh/s, tau,H s. This is the standard rate-latency argument independently derived; the book by Le Boudec and Thiran, https://leboudec.github.io/netcal/latex/netCalBook.pdf, gives the network-calculus framework (retrieved excerpts; no external traffic theorem imported). Actual downstream gridlock may violate positive service and the condition must not be assumed.

If a receiving generation on cell l has at most B_l bins and K_l route-offset marks, each bin emits at most one row per mark, so <=B_l K_l rows are generated regardless of the raw incoming event multiplicity. If only restrictions of each resident row remain in that cell (no intra-cell duplication) and the FIFO service bound holds, at most 1+ceil(H_l/dt) generations can remain. Therefore N_road <= sum_l B_l K_l (1+ceil(H_l/dt)) plus separately accounted initial rows until drained. This bound concerns road stock, not pending demand, bus/freight event rows or journey histories. Persistent delay/calendar owners need their own finite-history conditions. This is a conditional storage-complexity theorem, not a verified 24h bound for Valley. It identifies the specific physical service guarantee to measure rather than treating every large row census as a reason to raise the cap.

Exact algorithm lane: check per-cell uniqueness of offset for each tag; if true, stable tag counting scatter yields exactly the comparator order (tag,offset,source ordinal). The first pass detects conflicting offsets and then falls back to the old sort; the prefix scan and stable scatter preserve all reduction barriers. Cost O(N+K) vs O(N log N), with preallocated 12*K byte slots and existing ordinal workspace; actual allocation preflight charges both. Source code analogue Arrow RunArray, https://arrow.apache.org/rust/src/arrow_array/array/run_array.rs.html, distinguishes logical length from backing runs and supports zero-copy slices. Neither run-end encoding nor dictionary references reduce the mathematical logical count; they reduce storage and work when operators use the factorization.

Exact checkpoint lane: MFWHOLE4 uses explicit dictionary packet kinds 4..7 with independent flags for reusing prior key and code streams in the same queue. Values remain packet-local bit pairs. No pointer values on wire; code bounds/shape checked before use, old formats reject new kinds. Each explicit packet retains original logical length, order, endpoint and IEEE payload bits. The reader has a direct compact allocation admission; existing record cap and ledger validation remain unchanged. The optional native canonical digest streams the expanded MFWHOLE1 logical state (road, service, journey and identity) to SHA-256 without writing a second huge checkpoint. This is a semantic identity witness over that exact wire, not equality of compressed file bytes.
