## 지도: 반응 중 가속과 접근 시야

기존 정지거리식은 반응 중 속도가 일정하다고 가정했다. 반응시간 delta 동안 순가속도 상한 a_r, 이후 보장 제동감속 b_eff를 쓰면

    D = v*delta + a_r*delta^2/2 + (v+a_r*delta)^2/(2*b_eff) + margin,
    b_eff = b - g*q/sqrt(1+q^2) > 0.

v[m/s], delta[s], a_r와 b[m/s²], q는 도로 최대 경사 절댓값이다. a_r는 반응구간의 중력까지 포함한 순가속도 상한이다. v=10,delta=2,a_r=2,b=4,평지,margin=0이면48.5m로, 기존 상수속도 가정의32.5m보다 크다. 이 식을 법정 설계기준의 인증으로 부르지 않는다.

한 관측점만으로 접근구간의 시야가 보장되지 않는 반례를 만들었다. 접속점 앞 두 능선에서 가장 먼 관측점의 최소 시선 여유는+0.217265m였지만, 약29.31m 떨어진 중간 관측점에서는-0.259567m였다. 부모 gate는 접근로를 허용했고 새2m간격 screen은 거절했다. 각 시선은 bilinear 지형에 대해 연속 검사하지만 관측자의 위치는 유한 표본이다. 건물·이동 차량 가림과 모든 위치의 지속 시야를 인증하지 않는다.

선택 옵션 approach_step_m과 reaction_accel_mps2를 추가했다. 기본 None/0은 부모의 단일 관측점·상수속도 가정을 보존한다. 표본 예산 초과는 sight_sampling_budget, 접근길이 부족은 sight_extent_unknown으로 거절한다. 기존 생성기를 무시하는 연결 복구는 없다.

같은 네 형태·seed17·8활동지점·900m예산에서 각4개 접근로를 생성했다. 선택된 기하는 부모와 같았고 추가길이는800.003655,361.433371,800.003655,186.813959m다. 원지도 불변, cycle rank, 분할 길이 장부, 검사대상 비공유 중심선교차0을 확인했다. 대표지도가 보기 좋아졌다는 결과가 아니라 통제 반례의 잘못된 접속을 거절하는 기능이 추가된 것이다.

## 교통: 동결 gap을 실제 동역학으로

질량대표점은(class,mass,x,h,v,w)이며 h는 범퍼간 빈거리, v와 w는 뒤차/선두차 속도다.

    x'=v, h'=w-v, v'=u, w'=a_L.

속도는 연속이고 제동으로0에 도달하면 역주행하지 않는다. 앞차는 조건부 mark이므로 질량을 두 번 세지 않는다. 가중 대표점 수는 표현하는 차량량과 독립이다. 다만 a_L는 여전히 외생 scenario다. 따라서 실제 gap이 움직이는 조건부 모형이지 자기일관적인 전체 platoon의 상관 hierarchy를 닫은 것은 아니다.

선호속도는 기존 u_pref(h)=min(Uroad,Uclass,max(0,(h-h0)/T))다. 한 제어구간 Delta의 nominal 가속도는

    a_nom = clip[(u_pref-v)*(1-exp(-Delta/tau))/Delta, -b, a_max]

로 둔다. 이는 동결 target relaxation의 끝점 속도에 맞춘 held-control 근사다. 이것만으로 충돌회피를 주장하지 않고 다음 허용집합 안에서 최소 수정한다. jerk 제한은 이번 범위 밖이다.

## 최종 정지 위치만으로는 놓치는 반례

뒤차20m/s,b=8m/s²,앞차15m/s,B=2m/s²가 즉시 제동하면 최종 이동거리는25m와56.25m다. 최종 차이-31.25m만 보면 추가 간격이 필요 없다고 오해할 수 있다. 하지만 둘 다 움직일 때 상대접근량은5t-3t²이고 t=5/6초에서25/12m=2.083333m에 도달한다. Wolfram으로 정확한 값과 gap 미분식을 확인했다. 이 문제 계열은 기존 종방향 안전 연구에서도 다뤘으며 신규성 주장은 하지 않는다.

뒤차가 u를 Delta 동안 유지한 뒤 -b로 제동하는 변위를 X_f, 앞차가 보수적 초기속도 w_lower에서 즉시 -B로 제동하는 변위를 X_L라 두자.

    E(u) = sup_(t>=0)[X_f(t)-X_L(t)],
    U_admissible = {u in [-b,a_max] : E(u) <= h-h0}.

변위차는 정지·제어전환 시각 사이에서2차식이다. 따라서 구간 끝점과 상대속도가0인 내부 시각을 모두 검사한다. 시간 표본 최대값이나 최종 정지거리로 대신하지 않는다. u를 늘리면 뒤차의 전 궤적 변위가 감소하지 않으므로 E는 단조다. 허용 nominal은 그대로 사용하고, 아니면56회 이분법으로 허용되는 가장 가까운 값을 찾는다.

E(-b)>h-h0이면 ViabilityError와 입력 checkpoint를 반환한다. 현재 정보·보수적 bounds 아래 인증 가능한 제어가 없다는 뜻이며, 실제 충돌이 필연적이라는 정리는 아니다. 위치 snap, 순간속도 보정, 질량 삭제로 진행하지 않는다. 수치 잔차1e-9m는 사전 선언된 반올림 허용이며 물리 간격을 바꾸지 않는다.

## 정보와 조건부 안전 명제

truthful 선두속도 보고(w_obs,t_obs)와 가속도 하한 a_L>=-B로부터

    w_lower=max(0,w_obs-B*(now-t_obs))

를 얻는다. control 함수는 현재 실제 w를 읽지 않는다. 같은 허용 보고와 gap/v에서 숨은 실제 w만 바꾼 쌍세계 시험은 같은 제어를 반환한다.

명제의 추가 가정은 현재 정확한 gap과 자기속도 측정, 선두차 제동 bound, 즉시 제어 적용, 정지포화, 필요시 실제 full-braking fallback이다. 비교원리에서 실제 앞차 변위>=X_L이고 채택 구간 뒤차 변위=X_f이므로 h_actual(t)>=h-[X_f-X_L]>=h0다. 허용 제어를 반복하면 각 적용 구간의 간격 하한이 귀납적으로 유지된다. 재계산이 없을 때는 예정된 fallback을 실제로 적용해야 한다. 시뮬레이터가 실패 상태를 저장하는 것만으로 물리적 제동이 일어난다는 뜻은 아니다.

현재 gap은 직접 측정한다. gap 측정지연·잡음·actuator lag·끼어들기는 이 명제에 포함되지 않는다. 선두 속도 보고지연을 다뤘다고 지연된 모든 정보에 대한 안전을 입증한 것으로 확대하지 않는다.

분포 G의 한 구간 생성자는 v*d_x+(w-v)*d_h+u*d_v+a_L*d_w다. 가중 대표점의 push-forward는 양성과 질량을 유지하고 평균 gap 변화는 E[w-v]와 연결된다. 정확한 Markov 상태에는 보고/기억도 들어가야 하며, 이번 구현은 보고를 외부 입력으로 명시한다. 차종과 상관이 다른 대표점을 무조건 합치지 않는다. 도달시간은 같은 적용 궤적의 최초 root로 계산한다.
