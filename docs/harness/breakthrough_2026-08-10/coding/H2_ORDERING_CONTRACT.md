## Exact semantics

Let `N` be the brief's recursive Python normalization. Frozensets use
`("frozenset", tuple(sorted(N(item) for item in value)))`. Exact allowed
mappings use `tuple(sorted((N(key), N(item)) for key, item in value.items()))`,
followed by the existing adjacent normalized-key collision check. Sorting the
pair means an equal normalized key may force normalized-value comparison before
collision rejection. The final `json.dumps(..., ensure_ascii=True,
allow_nan=False, sort_keys=True, separators=(",", ":"))` bytes are observable
output, never a sort key.

The vector generator, every ordering differential, and every Task B replay gate
run under exact `env PYTHONHASHSEED=0` and record `sys.implementation.name`, the
full `sys.version`, executable, platform, and NumPy version when imported. Exact
comparison schedules and exception messages are valid only for that recorded
CPython 3.12 environment.

The candidate relations are:

- `VEQ(x, y)` returns exactly the result of `N(x) == N(y)`;
- `VLT(x, y)` returns exactly the result of `N(x) < N(y)` or raises the same
  exception;
- `PAIR_LT((k1,v1),(k2,v2))` reproduces normalized Python pair comparison;
- the same original iteration sequence is sorted by pinned CPython 3.12
  `sorted`/Timsort through `functools.cmp_to_key` views;
- a generic mergesort, private type rank, JSON token order, hash, or current
  implementation is not a substitute.

Complete finite/acyclic/exact-type/behavior-free/stable-read preflight occurs
before any JSON byte is yielded or digest state updated. The candidate retains
only original references, comparison/control frames, and one scalar token. It
does not retain `N(x)`, normalized trees, normalized key/member bytes, or
persistent prefixes.
